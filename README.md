# Karka AI

Karka AI is a React application built with Vite. The application UI, pages, reusable components, and mock data are consolidated in `src/App.jsx`.

## Project structure

```text
karka-ai/
├── index.html
├── package.json
├── package-lock.json
├── vite.config.js
├── .gitignore
├── README.md
└── src/
    ├── main.jsx
    ├── App.jsx
    ├── App.css
    └── index.css
```

## Getting started

```bash
npm install
npm run dev
```

## Validation

```bash
npm run build
npm run lint
```
